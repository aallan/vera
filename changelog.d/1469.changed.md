- **The prelude's names are reserved** ([#1469](https://github.com/aallan/vera/issues/1469)).  The prelude is a module whose names no declaration may take, in the entry file or in any module, whatever the declaration's shape.  **Breaking**: a function or a `where` helper named after one of the prelude's 23 functions (`option_map`, `option_and_then`, `option_unwrap_or`, `result_map`, `result_unwrap_or`, `html_attr` and the `json_*` accessors) is refused with `E151`, which exempted them before ([#815](https://github.com/aallan/vera/issues/815)); a `data` declaration, a `type` alias or a type parameter named after a prelude data type (`Option`, `Result`, `Ordering`, `UrlParts`, `Json`, `HtmlNode`, `Request`, `Response`), a built-in data type (`MdBlock`, `MdInline`) or a built-in type name (`Array`, `Decimal`, `Future`, `Map`, `Set`, `Tuple`) is refused with `E158`, which covered only a `data` declaration of a built-in type name.  A constructor may still share a prelude constructor's name.  A user `json_get` used to replace the prelude's inside `json_get_string`, so the program failed to load or returned a different value ([#1495](https://github.com/aallan/vera/issues/1495)); an entry-file `data Ordering { Lt, Same, Gt }` beside `compare` passed check and code generation dropped `main` ([#1496](https://github.com/aallan/vera/issues/1496)); a module's own `data Json` accepted a prelude `Json` value and read it through its own layout ([#1560](https://github.com/aallan/vera/issues/1560)), and an entry file importing it could not name it ([#1600](https://github.com/aallan/vera/issues/1600)); a `type Decimal` or `type Array<T>` alias beside a built-in value of that type built a module that fails to load ([#1553](https://github.com/aallan/vera/issues/1553)); and a type parameter named `Array` dropped its caller at compile ([#1556](https://github.com/aallan/vera/issues/1556)).  To upgrade, rename the declaration and update its uses: `examples/vera/collections.vera` declared `public data Option<T> { None, Some(T) }` and now declares `public data Maybe<T> { Nothing, Just(T) }`, and `examples/modules.vera` imports `Maybe`.  Four conformance programs that declared a prelude name are negative fixtures refused at check with `E158` (`ch08_alias_shadows_prelude_adt_name`, `ch08_prelude_adt_name_alias`, `ch08_module_prelude_adt_name`, `ch08_module_prelude_adt_contention_rejected`), and the spec's blocks that show the prelude's own declarations are marked as the declarations the compiler injects.  `vera.prelude.reserved_function_names()` and `vera.prelude.reserved_type_names()` are the one source of the set.
