- Both mutation lanes run a module's mutants against its **declared oracle** and no other test (`MUTATION.md` § Oracle, the rule `marker+name+family/1`): the class instruments whose `matrix` marker names the module, the test files named after it, and its families in `ORACLE_FAMILIES` (`scripts/mutate_diff.py`), the one source of `MUTATION.md`'s family table, which a self-test holds to it. A module nothing declares is listed in `UNDECLARED` with its reason (today `vera/__init__.py` alone), and a self-test fails on a module that is neither and on an entry no longer true. `tests/mutation_oracle.py` enforces the declaration in mutmut's copy: in the stats pass it takes each test out of mutmut's record for every function whose module's oracle does not hold the test's file (the map the lanes write, named in `MUTATION_ORACLE_MAP`), and both lanes copy their own checkout's plugin into the scratch tree. A survivor now means that no test the module declares kills it; a cell that kills it belongs in a file its module's oracle holds.
- The Mutation (diff) lane runs the union of the changed modules' declared oracles with the pull request's changed in-process test files, every class instrument at its sample under a seed fixed for the run; then each survivor on the diff's own lines is run again, the mutant active, against its module's class instruments at `--matrix=full` (pytest in mutmut's generated tree, at most 300 s a survivor, in the last 600 s of the budget): a failing test kills it, named in the record, and a look that finds none, does not finish or cannot run leaves it a survivor with its reason. It runs mutmut twice: a first pass with each changed function's first window mutant, then the rest in what is left of the budget, so a widely covered function is no longer left undecided whenever the budget runs out; the summary has a row per pass with each engine phase's start in seconds. It exits 3, red, when the diff is not measured: a changed function with mutants in its window had none decided (the budget ran out, the engine never reached it, every run ended undecided, or no test of its module's declared oracle reaches it); the headline counts them and each row says why. The JSON record holds every survivor's diff, asked of the engine within 300 s. `--list` prints the window's mutants from mutmut's visitor with no test run, uploaded as the `mutation-diff-list` artifact before the lane runs. A `workflow_dispatch` with `base` and `head` replays a recorded diff on the dispatched ref. A pull request is gated on its own lines: a survivor on a line the diff adds or modifies (or one that removes or replaces a child starting there) fails the check, and one on an unchanged line the two-line window pulled in is listed apart with its diff (`neighbour_survivors`), counted separately in the headline, and left to the standing sweep issue.
- The nightly mutation sweep cuts a night's modules into one run of whole modules a job, in the tree's order, the dearest bin as cheap as such a cut allows, and a slice runs the union of its modules' declared oracles under the cycle's matrix seed (`--matrix-seed=cycle-<N>`). A module `UNDECLARED` lists is never run: its sampled mutants are decided `undeclared`, counted apart and named in `mutation-survivors.csv`. The state keeps the oracle's rule and each module's oracle digest: a state from before the declared oracle, or under another rule, leaves its open cycle and starts the next at calibration 1.0, and a module whose oracle changed has its windows reopened. The calibration is the cycle's summed recorded cost over its summed estimate, and a new cycle starts at the closed one's whole ratio, where the factor had moved halfway each night. A listing is ordered with the budget's stop by its child's exit time. Nights run one at a time on each ref. A dispatch's `redraw` decides a closed cycle's sample again under the declared oracle on a branch state that closes no cycle, and `state_run` names the run to carry on from; each slice of a redraw names the test that kills each mutant the cycle killed and the declared oracle leaves, and the stitch writes `differential.json` and a table per module.
