- **`E608`, `E609`, `E610`, `E621` and `E623`** ([#1694](https://github.com/aallan/vera/issues/1694)).  Code generation's name-collision errors: two imported modules' same-named function (`E608`), data type (`E609`) or constructor (`E610`), a module's data type beside the prelude's (`E621`), and the entry file's beside a module's (`E623`).  Every declaration is compiled under its own link name, the prelude's names are reserved (`E151`, `E158`), and a value of one declaration's type that meets another's is a type mismatch at check, so nothing emits them, and `vera errors` no longer lists them.
