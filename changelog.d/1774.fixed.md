- **A clone's name qualifies a module's data type wherever the entry file's type of the same name meets it** ([#1774](https://github.com/aallan/vera/issues/1774)).  The clone-name display counted only module owners of a name, so a clone instantiated at an entry `Shape` and a module's `Shape` was spelled `pair$Shape_JShape` in a runtime contract message and its backtrace frame, beside a signature reading `(@Shape, @la.Shape, @Int -> @Int)`.  It reads `pair$Shape_Jla.Shape`, as `display_type_names` spells the signature: the entry's type, written bare in the message or in a clone's suffix, counts as an owner.
