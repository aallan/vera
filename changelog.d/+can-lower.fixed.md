- **A quantifier predicate whose parameter is a parameterised alias of `Int` or `Nat` reads the counter** ([#1506](https://github.com/aallan/vera/issues/1506)).  Code generation bound the counter under the alias's head, `Id` for `fn(@Id<Int> -> @Bool)`, while the body's `@Id<Int>.0` looks itself up under `Id<Int>`, so the reference dangled and compile stopped at `E699`, in a body and in a contract alike; where the enclosing function had a parameter of the same type, the reference read that parameter instead, and `forall(@Int, 3, fn(@Id<Int> -> @Bool) effects(pure) { @Id<Int>.0 < 3 })` answered `false` at a parameter of 7.  The counter is bound under the name the checker binds the parameter by.
