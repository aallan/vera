- **Mutation testing runs over a pull request's diff, in CI** (`scripts/mutate_diff.py`, `.github/workflows/mutation-diff.yml`).  On a pull request that changes a `vera/**/*.py` file, mutmut mutates the functions the diff changes, a function counting as changed when its code (its `ast`, docstrings set aside) differs from the merge base's or it is new.  It runs in a scratch tree of the head commit where every other function of a changed file carries `# pragma: no mutate block`, so mutmut generates the diff's mutants alone, and its oracle is the `[tool.mutmut]` test selection plus the pull request's own changed test files that reach the compiler in process.  The job summary has a row per changed function and the survivors' `mutmut show` diffs, and the JSON record is an artifact.  The job fails on a survivor (exit 1) and on a run that its 2,400 s budget, the engine, an undecided mutant or a mutant it cannot place stops short (exit 2), and it is not a required check.
  - `[tool.mutmut]` copies `scripts/` and `AGENTS.md` into mutmut's copy of the tree and deselects the two tests that parse `vera/verifier.py`'s own text.  21 of the selection's 6,554 tests failed inside the copy with no mutant active, and mutmut's stats pass, which runs the selection with `-x`, stopped every run at the first of them.
