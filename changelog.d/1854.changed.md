- A configured inference API key holding any character outside printable ASCII (a tab, a line end, another control character, or a character outside ASCII) is refused before any request is built ([#1854](https://github.com/aallan/vera/issues/1854)).  A key with a tab was sent as it was, since an HTTP header can carry one.  The `Err` names the variable that holds the key (`VERA_ANTHROPIC_API_KEY holds a character an HTTP header cannot carry ... Set it to the key alone.`), and quotes nothing of the key.  Upgrade: set the variable to the key alone, with no surrounding whitespace or line end.
