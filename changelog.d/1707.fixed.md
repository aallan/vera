- **A refuted postcondition's counterexample prints the result the body gives at the printed input** ([#1707](https://github.com/aallan/vera/issues/1707)).  An `ensures` is asked with the body's term in place of `@T.result`, so the declared result constant was in no query and the counterexample printed it as the model left it: `@Int.result = 0` beside `@Option<Int>.0 = Some(2)` for a `match` that returns 2, and `0` (or `False`) for every refuted `ensures` whatever the body's shape.  It is now the model's value of the body's term: `2` there, `13` for `@Int.0 + 10` at `@Int.0 = 3`, `5` for `@Int.1 - @Int.0` at 7 and 2, `1` for a call whose callee's `ensures` says so.
