- **`vera test` names a trial's arguments as the source does** ([#1757](https://github.com/aallan/vera/issues/1757)).  A trial's arguments were labelled in parameter order with each type counted from 0 left to right, so the first of two `@Nat` parameters was reported as `@Nat.0`, the name the source gives the second, and the labels contradicted the function's own `requires`.  A parameter of type `T` is now labelled `@T.n`, *n* the number of later parameters of type `T`, the De Bruijn order the source's slot references use: `pair(@Nat, @Nat -> @Int)` with `requires(@Nat.1 <= 0 && @Nat.0 >= 5)` reports `@Nat.1 = 0, @Nat.0 = 5`.  The text report, the `--json` report's `args` and the E703 description of a refuted proof each read the corrected labels; the arguments are listed in the parameters' order, as before.
