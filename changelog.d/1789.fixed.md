- **`vera ast --json` prints a refused program's diagnostic in the envelope the other commands print** ([#1789](https://github.com/aallan/vera/issues/1789)).  `vera ast` printed a parse or transform refusal as text on stderr whatever `--json` said, so `vera ast --json` exited 1 with an empty stdout; it prints the envelope `vera compile --json` prints for the same program, `{"ok": false, "file": ..., "diagnostics": [...], "warnings": []}`.
