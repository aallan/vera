- Both mutation lanes let mutmut's copy cache bytecode, and `tests/mutation_oracle.py` records each test that fails in the stats pass or the clean run to a file the lane reads ([#1829](https://github.com/aallan/vera/issues/1829)). A mutated module compiles in tens of seconds (`vera/checker/calls.py` with its mutants inlined is 24 MB and takes 47 s) and loads from its `.pyc` in a fifth of a second, and under the fork server every pass and every mutant's worker is a fresh process that compiled each mutated module it reached, which made a mutant cost three to ten times what it had; and the fork server's stats child kept its pytest output from the log, so a test that failed in the copy stopped the slice as an engine failure with no name instead of being dropped. The nightly sweep's schedule is paused while its sample is drawn by line rather than by mutant; a night runs on demand meanwhile.
