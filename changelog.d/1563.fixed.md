- **A judgement on what an earlier diagnostic refused reports nothing further** ([#1563](https://github.com/aallan/vera/issues/1563)).  A bare call to a name a function refused for redefining a built-in took (`E151`) is no longer held to the built-in's signature, which drew `E202`, `E314` and `E313` at the call; a `data` declaration refused for taking a built-in type's name (`E158`), `Map`, `Set`, `Array`, `Decimal`, `Tuple` or `Future`, is not registered, as a primitive's never was, so its constructor builds no value of the built-in (`let @Bool = Wrap(1)` was `E170`, "value has type Map") and `@Map<String, Int>` keeps the built-in's type arguments (`E135`), above the declaration as below it; a type name nothing declares (`E136`) is compatible with every type, as an unknown is, through a generic's substitution too, so the `let`, return, argument, destructure, comparison and operator (`+`, `-`, `<`, an index) that name it draw no `E170`, `E121`, `E202`, `E142`, `E243`, `E140`, `E147`, `E143` or `E161`, nor a `requires` (`E123`), an effect operation's argument (`E204`) or `apply_fn` (`E202`), every early guard reading one shared predicate; and a `match` or a destructuring `let` over a typed hole is not judged for coverage, so `match ? { Some(@Int) -> @Int.0, None -> 0 }` and `let Tuple<@Int, @Int> = ?;` report the hole's `W001` alone, not `E313` beside it.  In the verifier, a refused binder holds its predicate for the rest of its scope in every spelling: a `@Nat` binder's sign, guarded at the bind, as a refined binder's predicate (`Some(@Nat) -> need_nn(@Nat.0)` drew `E501` beside its `E503`), and a destructure's component as a `let`'s binder, in every walk that reads one (`let Tuple<@Pos, @Int> = Tuple(@Int.0 - 5, 1); need_pos(@Pos.0)` drew `E501` beside its `E505`), and a guarded binder's fact reaches a query through another guarded binder's fact that names it.  The same reading closes [#1696](https://github.com/aallan/vera/issues/1696)'s destructure line: a component of a stand-in, `let Tuple<@Pos, @Int> = Tuple(get(()), 1)`, discharges the call its `let @Pos = get(())` twin discharges, where it was a Tier 3 runtime check (`E532`).
