- **A call precondition refuted only over a stand-in is a runtime check in every position** ([#1696](https://github.com/aallan/vera/issues/1696)).  The rule of [#804](https://github.com/aallan/vera/issues/804), under which a function body's call over an opaque value was refused with E501 whatever the value, is retired: such a call takes the E532 demotion, with the callee's own check behind it, and is E501 only where the precondition is false for every value the stand-in could take.  A program refused at such a call now verifies with one more runtime check.  The E522 postcondition warning and the E504/E506 undecided rationale name a stand-in for a value the verifier cannot translate, where they named an effect operation's.
