- The nightly mutation sweep no longer scores a function evaluated at import as survivors no test could kill ([#1740](https://github.com/aallan/vera/issues/1740)). mutmut forks a mutant's worker after the modules are imported, so a function every reference to which is a call run at import (a module or class body, a decorator, a default), or a call from another such function, never runs under its mutant; none of its references may be a stored name, a call from code run later, or a test's. A rule over the sources (`at_import_units`, by `ast`) finds them, 31 in the tree, among them `vera/__init__.py`'s `_read_version`, `vera/ast.py`'s `_spelling` and `_stage`, and the four the nights scored as survivors: `monomorphize._builtin_return_tables`, `trap_registry._kinds` and `_emitters` in cycle 2, `fold._check_order` in cycle 3. Their sampled mutants are decided `at_import` without running: counted apart, outside the score's total and the survivor list, never planned, and a window scored before the rule is decided again by it.
