- **`E619`** ([#1679](https://github.com/aallan/vera/issues/1679)).  Code generation's refusal of an `Eq` constraint whose type argument a constructor fixed only in part (`id1(MkErr(5))` on `Res<A, B>`, `A` unfixed).  A type argument no argument fixes is instantiated at the phantom type, as every other one is, at which `Res<Bool, Int>` derives `Eq`, and the program runs.  `vera errors` no longer lists the code.
- **`E622`** ([#1679](https://github.com/aallan/vera/issues/1679)).  The verifier's refusal of a generic call whose type argument its own discovery could not infer.  The instances are derived from the check's record of each call, which holds what the call's arguments fix, and a type argument no argument fixes is instantiated at the phantom type, so no call is left uninferred.  `vera errors` no longer lists the code.
