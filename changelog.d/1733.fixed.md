- **`json_parse` builds a document of any width on both hosts** ([#1733](https://github.com/aallan/vera/issues/1733)).  The native host kept every string's, array's and object's roots on the shadow stack until the whole document was built, so a document past about 4,090 of them overflowed it (`#692: host shadow-stack overflow`): the widest that parsed was 4,091 members for an object of numbers and for an array of strings or of arrays, 2,045 for an object of strings or of arrays and for an array of objects, and 1,363 for an object of objects, and only an array of numbers had no limit.  Each string, array and object is now built in a shadow-stack window of its own and holds no root once it is written, so every one of those shapes parses at 20,000 members.  The browser runtime rooted each member of an object until the object was built, so an object of 4,100 members overflowed there (`GC shadow stack overflow`); it builds the object from two rooted arrays now, and every shape parses at 10,000 members.
