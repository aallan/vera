- **A closure whose body destructures a tuple compiles.**  The closure's free-variable walk read no destructuring `let`: it never walked the source and never counted the bindings, so `let Tuple<@Int, @Int> = …;` in a closure body made a later reference look like a capture the enclosing scope does not hold, and the function holding the closure was dropped ("unsupported expressions") with every caller of it.  The walk is now `vera/fold.py`'s scope walk, which reads the destructure where `vera/binders.py` lists it.
