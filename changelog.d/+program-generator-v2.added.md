- **The program generator, version two, and a fourth differential.** `tests/program_generator.py` writes recursion with `decreases` (a `@Nat` measure its `requires` bounds, a mutual pair through a `where` helper, and a structural measure over a recursive data type), generic helpers called only at types their `where` clause admits, plain and refinement type aliases at a slot's head and inside a type argument, a module beside the entry that the entry imports by a selective list of what it uses, `Array`, `Map`, `Set` and `Tuple` values with their readers (`array_length`, an index under the bound that proves it, `array_fold`, `map_get`, `set_contains` and `set_size`), `handle[State<Int>]`, `handle[State<Nat>]` and `handle[Exn<T>]` with `throw`, and pairs of parameters of one type under the non-commutative operators, whose `ensures` holds for the operands' order the generator meant and not for the other; every contract is still true by construction.  `tests/test_program_generator.py` holds each program to a fourth differential: the program and four edits of it (a literal moved inside its interval, a `let` added, a pair's operands swapped, a function added with a call to it, a `requires` tightened, a contract broken and restored) go in order to one warm `VerificationSession`, as the language server sends a document's text, and each text alone to a fresh session, and the two must report the same obligations, with the same statuses at the same places, and the same diagnostics.
  - `KNOWN_CLASSES` counts version one's two `nat_bind` classes as the one mechanism of [#1695](https://github.com/aallan/vera/issues/1695) they are (a value the declarations make non-negative, which code generation's declared-name rule does not read as one), and adds three of #1695's that version two's shapes meet: a narrowing into a refinement of `Nat`, recorded once and checked twice; a refinement check on a value the declarations already give the refinement; and a join of a refined arm with an unrefined one, which the checker types as the refinement.  Each predicate reads the program as written, never the checker's tables.
  - `.github/workflows/nightly-generator.yml` runs 1,200 seeds a night, where it ran 5,000: a version-two program with its edits costs 6.9 times a version-one program, and the warm differential is 0.87 s of its 1.20 s.  Every pull request runs ten pinned seeds that between them write every construct of the grammar.

They also met an `if` or a `match` with no arm code generation can type (two folds, a `throw` beside a fold, two handlers), which compiles to a module that does not load, and warm counterexamples that differ from a fresh session's for the same refuted clause.
