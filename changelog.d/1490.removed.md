- **`E604` and `E605`** ([#1490](https://github.com/aallan/vera/issues/1490)).  These were the compilability check's codes for a parameter type and a return type with no WASM representation, and the registry titled them for state effects.  The check now emits `E600` and `E601`, the codes of those concepts, which the signature compile emits for the same two, and `vera errors` no longer lists `E604` and `E605`.  To upgrade, a consumer keyed on `E604` keys on `E600`, and one keyed on `E605` keys on `E601`.
