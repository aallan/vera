- A fact the verifier holds about a value still holds once the value is stored in a constructor's field and read back ([#909](https://github.com/aallan/vera/issues/909)): a callee's `ensures`, a refined return type, and a refined or `@Nat` parameter.  `let @Box = MkBox(mag(-5));` followed by a `match` that returns the field proves `ensures(@Int.result >= 0)` at Tier 1 where `mag` ensures it, and so do a generic `Box<T>`, an `Option`, a nested constructor, a constructor built in each arm of an `if`, and an array literal.  The verifier at 0.2.8 already proves them: the limitation's rows in `KNOWN_ISSUES.md` and `ROADMAP.md` were out of date and are removed, and `tests/test_adt_field_facts_909.py` pins each shape.  A `Nat` component of a value the function did not build still carries no `>= 0` where it is read at `@Int` ([#1814](https://github.com/aallan/vera/issues/1814)).
