- **The nightly mutation sweep's clean pass no longer dies on the first WebAssembly trap** ([#1745](https://github.com/aallan/vera/issues/1745)).  `tests/test_wasi_target.py` built its wasmtime `Engine` and `Linker` at import, so mutmut's fork server, which imports every selected test module once in a collect-only session and forks each run from that process, installed wasmtime's trap handlers during that session and lost them when pytest's faulthandler teardown restored the handlers it had found; every forked run then met its first trap with no handler, and the sweep's first night ended all seven slices with SIGILL (exit -4) before deciding a mutant.  The module builds them on first use, `tests/test_import_time_wasmtime_1745.py` holds every test module to that (no wasmtime object constructed at module level), and a slice record whose engine log holds a Python fault dump keeps the dump's first lines, which name the test, beside its last.
