- **An array of `Bool` or `Byte` that `set_to_array`, `map_keys` or `map_values` returns holds the elements that went in** ([#1729](https://github.com/aallan/vera/issues/1729)).  The hosts wrote such an array in four-byte cells where generated code reads one byte an element, so `set_to_array` of the `Set<Byte>` {7, 200, 3} printed `200 0 0` natively and `7 0 0` in the browser, and `map_keys` of a `Map<Bool, Int>` printed `false false`.  The arrays are written by the module's own code now, in the cells generated code reads.
