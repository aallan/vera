- An element refinement whose predicate calls a function is no longer stated under the array's index quantifier ([#1929](https://github.com/aallan/vera/issues/1929)): the call's result is one constant for every element, so `type R = { @Int | ident(@Int.0) == @Int.0 }` made every element of an `Array<R>` equal and `vera verify` proved `@Array<R>.0[0] == @Array<R>.0[1]`, which a run refutes.  A fact is stated of the elements only when it is about each element alone, at the element and at each position inside it; a goal with such a fact withheld is a runtime check.
