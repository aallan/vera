- **`E603`, `E606` and `E611`** ([#1681](https://github.com/aallan/vera/issues/1681)).  Code generation's warnings for a function whose row named an effect it does not compile, or `State` or `Exn` without a type argument.  The check refuses each such row entry (E340), so nothing emits them, and `vera errors` no longer lists them.
