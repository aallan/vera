- The language server's diagnostic ranges start on the character `vera check` puts its caret under ([#1637](https://github.com/aallan/vera/issues/1637)).  A diagnostic's column is 1-based, as every stage writes it and the command line reads it, and the server read it as 0-based, so every published range started one character late: `E200` at line 6, column 3 of `  missing(@Int.0)` covered `issing`, and a diagnostic on the last character of a line, `E040` on a pipe's `1`, had an empty range past it.  A range now starts at the column and ends where the name or slot reference there ends, one character on, or at the end of the line.
