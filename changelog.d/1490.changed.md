- **A command's own refusals print as every other diagnostic prints** ([#1490](https://github.com/aallan/vera/issues/1490)).  A refusal of the command line, and a runtime trap, printed one `Error: ...` line on stderr.  Each now prints the diagnostic block: a header such as `[E900] Error at <file>, line 0, column 0:`, then the description, the rationale, the fix and the spec section.  A trap's source backtrace follows its block.  To upgrade, a script that matched `Error:` on stderr matches the description, which holds the text it matched.  The `--json` envelope keeps every field it had.
