- An exception that leaves an export no exception boundary wraps is named `uncaught_exception` under wasmtime 51 ([#1894](https://github.com/aallan/vera/issues/1894)).  wasmtime 51 reports it from a component call as `uncaught exception propagated out of component`, where 50 said `thrown Wasm exception`, and the WASI 0.2 host, which reads the kind from that text, reported the kind `unknown`.  The trap registry now holds both texts, and wasmtime's `UNCAUGHT_EXCEPTION` trap code, which it lacked.  A module compiled from Vera was not affected: every export that declares `Exn<T>` has a boundary that names the exception itself.
