- A refinement the type checker recorded a join at is no longer a premise of the value: an `if`, `match`, block or `handle` is established at the one type its leaves share, and at its base where they differ (#1716).  A payload handed on as `g(if c then { @Option<Int>.0 } else { None })` into an `@Option<PosInt>` formal, returned or bound by `let` that way, or a `State` handler in a `match` arm returned at `@Option<PosInt>`, read `verified` while the run broke the payload; each is now refuted (`E505`).  An `Exn` handler whose body joins an `@Int` and a `@PosInt` no longer proves `ensures(@Int.result > 0)` from its recorded `PosInt`; the postcondition is a runtime check (`E522`), as it was before #1833.
