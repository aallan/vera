- **`Map` and `Set` are persistent hash tries in the module's own code, and their operations leave the hosts** ([#1676](https://github.com/aallan/vera/issues/1676)).  A map or a set was a bucket every host decoded into a dictionary and encoded again on each copy-on-write operation, so an operation cost the collection's size and a fold of `map_insert` over n keys cost n².  It is now a trie of 32-way branches in the module's heap, one branch for each five bits of a key's hash, and each of the fourteen operations is a function the module carries, generated for the key, value and element representations the program uses (`vera/wasm/hamt.py`).  An update copies the branches on its key's path, at most thirteen, and shares every other block with the collection it was given, which it leaves as it was.  The fold of `map_insert` over 10,000 keys that took 50.4 s natively and 16.0 s in the browser runtime executes in 41 ms natively and runs in 0.04 s in the browser harness; 100,000 keys take 1.75 s.
  - The order is insertion order for both, as spec §9.7.1 already promised a `JObject`'s members: `map_keys`, `map_values` and `set_to_array` read a key inserted again at its first position, and a removed key loses its position.  Keys compare by SameValueZero, a `Float64` key stored canonical (`-0.0` as `0.0`, every NaN as one), and a `String` key by content.
  - No host implements a map or a set: `vera/runtime/map.py`, `set.py` and `collections.py`, the bucket codec in `vera/runtime/heap.py`, the browser runtime's map and set bindings and the WASI server world's in-guest map operations are deleted, with the registry's fourteen `map_*` and `set_*` host-import rows and the `map` and `set` families.  The JSON and HTML hosts and the `vera serve` driver build a `Map<String, V>` with one call of the module's exported `map_from_arrays$ks_v<t>` and read one through `map_keys$ks` and `map_values$v<t>`, and so does the WASI server world's adapter for a `Request`'s and a `Response`'s headers.
  - Both WASI worlds run every `Map` and `Set` instance, where the cli world refused both families and the server world every instance but `Map<String, String>`.
  - A module whose only wrapped values were maps and sets no longer carries the 64 KiB wrapper table, nor does a JSON or HTML module: the table holds `Decimal` values and pending async requests.
  - The scorecard's host built-ins hand-mirrored across hosts fall from 53 × 2, plus WASI's 10 map operations, to 39 × 2, plus none.
